2. Project Description & Problem Statement

2.1 Project Description & Background

In clinical outpatient environments, medical triage is a vital diagnostic gateway where incoming patient symptoms are prioritized for care. Conventional hospital triage relies heavily on manual questioning by clinical staff, leading to cognitive fatigue, operational bottlenecks, and triage variability during peak hours. AuraDX is an AI-assisted Clinical Decision Support System (CDSS) that introduces a dual-paradigm architecture:

  • Unstructured NLP Engine: Employs text cleaning, WordNet lemmatization, TF-IDF vectorization, and Logistic Regression on conversational narratives (Symptom2Disease) to evaluate natural language patient self-descriptions.
  • Structured ML Engine: Implements a compressed Random Forest Classifier trained across 377 binary symptom flags covering 673 unique diseases (Diseases & Symptoms) for clinical intake checklists.

Both engines are integrated into a single, responsive Flask web application providing side-by-side comparative predictions and real-time confidence scores.

2.2 Problem Statement

Healthcare intake processes suffer from three primary bottlenecks: (1) Narrative Subjectivity: Patient self-descriptions are noisy, ambiguous, and non-standardized; (2) High Class Cardinality: Comprehensive symptom checklists encompass hundreds of diseases with overlapping presentations; (3) Lack of Comparative Dual Verification: Current tools evaluate either text or checklists in isolation without cross-paradigm verification.

3. Existing System & Its Limitations

Existing System: Current methods rely on manual clerical documentation, static rule-based lookups, or generic single-format internet symptom checkers (e.g., WebMD, basic keyword searches).

  • No Comparative Cross-Validation: Systems operate exclusively on either structured forms or simple keyword searches, lacking multi-model verification.
  • Fragility to Colloquial Language: Rule-based systems fail to handle typos, synonyms, or conversational phrasing.
  • High Memory Footprint: Uncompressed high-cardinality multi-class models exceed 6+ GB, preventing local clinic deployment.
  • Throughput Delays: Manual triage intake causes severe backlogs during peak outpatient intake.

4. Proposed System & Key Advantages

AuraDX solves these shortcomings by deploying two complementary machine learning engines into a unified platform:

  • Dual-Paradigm Assessment: Evaluates free-form narrative descriptions (NLP: 95.8% accuracy over 24 diseases) and structured symptom vectors (ML: 81.8% accuracy over 673 diseases) simultaneously.
  • Memory-Compressed Deployment: Gzip serialization reduces model size from 6.6 GB to 41.4 MB (160x reduction) for instant cold starts.
  • Interactive Triage Dashboard: A lightweight Flask web application with a glassmorphic UI displaying live confidence meters.

5. Project Scope & Measurable Objectives

Project Scope:

  • In-Scope: Automated text preprocessing (NLTK), high-cardinality multi-class classification on 19,700+ records, compressed model persistence, and a live web application dashboard.
  • Out-of-Scope (Boundaries): AuraDX is an academic decision-support prototype and does not replace certified physician diagnoses or autonomously prescribe medication. Direct live EHR integration is reserved for future iterations.

Specific Objectives:

  • Train an NLP text classification pipeline achieving >90% accuracy on natural language symptom descriptions.
  • Train a compressed 50-tree Random Forest classifier across 673 diseases with memory-safe chunked loading.
  • Implement model persistence via Joblib compression to reduce file size from 6.6 GB to under 45 MB.
  • Develop a full-stack Flask web application displaying side-by-side comparative predictions and confidence scores.

6. Key Features & Functional Modules

  • Module 1 — NLP Preprocessing Pipeline: Strips punctuation, removes stopwords, performs WordNet lemmatization, and builds TF-IDF n-gram matrices.
  • Module 2 — Structured Multi-Class Classifier: Evaluates 377 symptom flags across 673 diseases via an optimized Random Forest ensemble.
  • Module 3 — Model Serialization & Compression: Compresses sparse probability matrices into compact .joblib binaries for sub-second execution.
  • Module 4 — Keyword Symptom Mapper: Scans free-form user text, matches keywords against the 377 symptom vocabulary, and builds binary feature vectors on the fly.
  • Module 5 — AuraDX Interactive Dashboard: A glassmorphic dark-mode web interface with quick-tag insertion and animated confidence meters.
